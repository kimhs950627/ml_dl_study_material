## 🟠 중요 (v2 에서 수정)

1. **쪽번호와 러닝 푸터가 없다** — 19쪽짜리 기술 문서인데 "p.13 참조"가 불가능했다.
   Chrome headless 인쇄는 CSS `@page` margin box 를 지원하지 않으므로, 렌더 후 PyMuPDF 로 찍었다.
   → `stamp_pages.py` 추가. 하단 규칙선 + 좌측 `softmax와 cross-entropy의 수치 버그 · arXiv:2610.31642`
   + 우측 `n / 19`. 표지는 제외. 한글 폰트는 `NotoSansCJK-Regular.ttc` 를 임베드(없으면 ASCII 로 폴백).

2. **숫자 열이 좌측 정렬** — `-5.96e-8` / `-4.60e-8` 처럼 지수 표기 열이 자리수로 정렬되지 않아
   눈으로 비교가 안 됐다. (`td.n` 은 `text-align` 미지정이라 `th,td` 의 left 를 물려받음)
   → `td.n,th.n{text-align:right}` (78행). tabular-nums 는 이미 있었으므로 정렬만 고치면 됐다.

3. **그림 라벨 8.25pt · 코드 8.25pt** — 인쇄 최소 9pt 기준 미달. SVG 는 `font-size="11"` 속성,
   코드는 `pre{0.76rem}` × `code{0.92em}` 이중 축소가 원인이었다.
   → `.fig > svg text{font-size:13px}`(91행, 9.75pt), `pre code{font-size:1em}`(86행, 9.1pt).

4. **꼬리 페이지에 40~60% 공백** — STEP 07·09·11 이 두 쪽으로 넘어가면서 둘째 쪽이 비었다.
   그냥 여백으로 두면 "조판 사고"로 읽힌다.
   → `.memo` 블록(4줄 괘선 + 라벨)을 세 곳에 넣어 **검산용 필기 공간**으로 용도를 부여(532·641·760행).
   STEP 09 는 0.99쪽으로 한계에 붙어 있어 본문 2줄도 함께 압축했다.

5. **표지 밴드가 페이지 하단에서 끊김** — `min-height:250mm` 가 @page 여백(265mm)보다 작아
   아래 15mm 가 흰 띠로 남았다. → `262mm`(106행). 동시에 표지 하단에 출처·라이선스·검증 상태를
   붙여(`.metafoot`, 48행) 아래쪽 공백을 정보로 채웠다.

## 🟡 제안

6. **`이 책` / `워크북` / `안내서` 혼용** — 같은 문서를 세 이름으로 부른다.
   → v2 에서 전부 `워크북` 으로 통일했다(표지 meta·본문 3곳).

7. **그림 2 의 축 라벨이 곡선과 겹침** — `고친 구현: 이론값 그대로` 라벨을 y=212 → 252 로 내리고,
   `margin m` 캡션이 눈금 `20` 과 겹쳐 삭제. 10단위 그리드선을 추가해 로그 눈금을 읽기 쉽게 했다.

8. **도해 색이 4색** — 악센트 1개 원칙의 예외. 색만으로 구분하지 않고 라벨·선 스타일(실선/점선)을
   병행했으므로 유지. 흑백 인쇄에서도 구분된다.

9. **연습문제 번호 체계 불일치** — 본문은 `확인문제 2-1`(장-번호), 부록은 `1`~`10`.
   → 부록을 `연습 1`~`10` 으로 바꾸는 안을 검토했으나, 정답지와의 대응이 이미 1:1 이라 유지.

10. **표에 번호·캡션 없음** — `표 1` 식으로 부르지 않으므로 문제 없음. 원문 표를 인용할 때만
    `논문 Table 1` 로 구분하고 있다.

11. **STEP 08(코드) 페이지가 68%** — 코드 블록 `break-inside:avoid` 때문에 뒤로 밀린 결과.
    코드를 쪼개는 것보다 낫다고 판단해 유지.

12. **한글 조판** — `word-break:keep-all` + `line-break:strict` 로 어절 분리 0건(page-check 확인).
    영문·수식 혼용 문장에서 줄바꿈이 수식 중간에 걸리는 곳이 2군데 있었으나, MathJax 인라인은
    어절 단위로 끊기지 않아 그대로 두었다.

## 남은 선택 (사용자 결정)

- 표지 가운데 큰 여백을 그대로 둘지, 스텝 지도를 표지로 올릴지.
- 부록 연습문제 번호를 `연습 1`~`10` 으로 바꿀지(현재는 `1`~`10`).
- 흑백 인쇄를 전제로 도해 4색을 2색(실선/점선 + 명도)으로 줄일지.
